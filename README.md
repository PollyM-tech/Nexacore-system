## Overview

Lintech is an ISP billing, network management, and automation platform designed for internet service providers.

| Domain | What it does |
|---|---|
| **Customers** | Profiles, zones, packages, provisioning, and online monitoring |
| **Billing** | Bills, invoices, payments, allocations, and account status |
| **MikroTik** | RouterOS integration, PPPoE provisioning, profiles, and live sessions |
| **OLT / ONU** | SNMP discovery, ONU monitoring, Rx power, and PON information |
| **Bandwidth** | Live throughput, usage snapshots, and reports |
| **SMS** | Gateway support, templates, and customer communication logs |
| **Support** | Support tickets and threaded customer communication |
| **Portal** | Customer self-service for billing, payments, and support |
| **Scheduler** | Background jobs using django-q2 |
